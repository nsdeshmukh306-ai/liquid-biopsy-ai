§ 4. DIAGNOSTIC ANALYSIS — WHY AUC = 0.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Two independent problems explain AUC=0.0:

PROBLEM 1 — FEATURE PIPELINE INCOMPATIBILITY (PRIMARY CAUSE)

  The training data (GEO GSE149438) and our external extraction use
  different fragment binning schemes:

  Training data (GEO original authors):
    - Values are discretised to 0.01 precision (multiples of 0.01 only)
    - Suggests ~100 reads per sample in the feature window
    - Modal bin varies widely: healthy mean=60.1±13.1, cancer mean=15.2±24.1
    - If bins are ordered by fragment size 100–400bp (2bp/bin), the training
      healthy mode at bin~60 = 220bp and cancer mode at bin~15 = 130bp
    - These are biologically plausible: short cfDNA enriched in cancer ✓

  Our external extraction (Nextflow + BWA + TLEN):
    - Smooth, high-resolution histograms from 350,000–390,000 fragments
    - Modal bin at bin_33 (~167bp nucleosomal peak) for all 3 samples
    - Values are continuous (e.g., 0.038970...)
    - PROBLEM: our bin_33 ≈ 167bp is at the SAME range but the external
      fragments are 3× denser at 167bp than training data average
      (training mean at bin_33 = 0.012; external = 0.039)
    - This means after StandardScaler transform: external bin_33 appears
      as a large positive outlier (Z ≈ +4), pushing the model toward cancer

  Impact: After scaling with the training scaler:
    Training test set: scaled range [-2.58, +14.46], mean ≈ 0
    External cohort:   scaled range [-12.76, +2.61], mean = -0.23

  The external features are predominantly NEGATIVE after scaling (features
  below the training distribution mean), plus some highly positive spikes
  at the nucleosomal peak. The model has never seen this pattern.

  Root cause: The GEO training features were extracted with low-coverage
  sequencing (~100 reads → 0.01 resolution), while our external features
  come from 350K+ aligned read pairs (smooth, high-resolution histograms).
  These represent fundamentally different data resolutions.

PROBLEM 2 — SAMPLE SIZE (n=3) IS STATISTICALLY UNINFORMATIVE

  With n=3 (1 healthy, 2 HCC), any AUC value from 0.0 to 1.0 is compatible
  with the true AUC anywhere in [0, 1]. No statistical conclusion is possible.

CONCLUSION ON EXTERNAL AUC:
  The observed AUC=0.0 is a feature pipeline incompatibility artifact,
  not a biological finding. The model receives out-of-distribution inputs
  and responds with maximum-confidence predictions (default: cancer,
  the majority class at 84.7% in training). This is expected behaviour
  for any neural network encountering covariate shift.

  To achieve valid external validation, one of:

  c) Use a cross-study feature harmonisation approach (ComBat, etc.)
     to correct for batch/pipeline effects between datasets

CONFIRMED (from limitations_FINAL.txt):
  §9.1 DATA SOURCE MISMATCH — confirmed; pipeline incompatibility prevents
       zero-shot application to independently processed features.
  §9.7 NO INDEPENDENT VALIDATION — confirmed; could not obtain valid AUC.
  §9.3 EXTERNAL PREPROCESSING — confirmed; authors' feature extraction
       uses different resolution and possibly different bin range.

NEW FINDINGS from this expansion:
  A. GEO FEATURES ARE LOW-RESOLUTION: GSE149438 frag_bin values are
     discretised to 0.01 precision, consistent with ~100 reads per sample
     total in the feature window. Our pipeline uses 350K+ fragments.
     Training on low-resolution features then applying to high-resolution
     features causes severe covariate shift.

  B. ENA INTERLEAVED FASTQs ARE TRIMMED: ENA's .fastq.gz (non-paired)
     files for PRJNA291063 contain only 8–38 bp quality-trimmed adapter
     sequences, not full-length reads. This is an ENA data submission
     artifact. Full paired files (_1/_2) are required.

  C. BIGBED WPS FOOTPRINTS ≠ cfDNA FRAGMENTS: GSE71378 BigBed files
     store Windowed Protection Score nucleosome footprint peaks (7–150 bp),
     NOT cfDNA fragment sizes (100–400 bp). The two signals are related
     (both reflect nucleosome positioning) but are computed differently
     and cannot be interchanged as model input.
